Comienza con el README

Este archivo es la guía, no la aplicación. Para abrir el sistema necesitas iniciar su servidor.

  1. Descomprime todo el ZIP.
  2. Lee README.md.
  3. Elige MySQL con Docker para validar la entrega, o SQLite para una revisión rápida.
  4. Inicia el servidor y abre http://localhost:5000.

MySQL con Docker

Dentro de esta carpeta, abre PowerShell y ejecuta:

Copy-Item .env.example .env
notepad .env

Configura las contraseñas y la clave de sesión. Luego:

docker compose up --build -d
docker compose logs -f app

Usa admin y la contraseña elegida en DEMO_PASSWORD. Los seis perfiles y los pasos detallados están en el README.
